### 第41集｜证词恨意 → 三天约期 → 赐力启程 → 三子自信

**入口（40→41）**：狼王城堡——证词还在手上/案上；Ava OS 余恨未消。  
**功能**：决定回夜嚎；与 Roman 说清；赐力；三子误解「跟回去」。  
**人物**：Ava、Roman、Theo（可）；Lucas、Ryan、Jason（后半）

**节拍**  
1. Ava：我要回夜嚎，问 Silas 十年前到底做了什么。  
2. Roman：我陪你。 / Ava：这仇我自己问；**婚礼前三天内赶回**。  
3. Roman 允；掌心渡**额外狼力**入她（可见紫金气息）——傍身防身，非遥控。  
4. 转场：三子拦路或跟出城，热脸「你终于肯回来了」。  
5. Ava：我回去是问罪，不是回家。  
6. 三子互壮胆（自以为是多轮）：她肯同行=还爱我们/哄哄就会留下。  

**拉扯**：Ava↔Roman 去留；Ava↔三子「问罪≠复合」。  
**亮点**：三天婚期沙漏 + 赐力；三子自信笑话。  
**出口→42**：同行上路/入界。

### 第42集｜热脸哄劝 → 禁药再亮 → 翻坏

**入口**：承接同行；夜嚎方向林道或城门将入。  
**功能**：提醒观众禁药还在；三子被再次药控。  
**人物**：Ava、Lucas、Ryan、Jason、Bella

**节拍**  
1. 三子轮流哄：十年、道歉、Bella 已逃、回夜嚎就好。  
2. Ava 冷驳：我只找 Silas。别碰我。  
3. Bella 暗处/半现身；指尖拧**心形项链**，幽蓝药息入三子鼻息——瞳底闪红。  
4. 对白要让观众「想起这药」：项链特写、气味、瞳色，但**不解释完整机制**。  
5. 三子语气骤变：凶、占有、威胁「必须留下」。  

**拉扯**：哄→冷→药下→变脸。  
**亮点**：药控打回「有限醒悟」。  
**出口→43**：坏态成立，开始动手级拦阻。

### 第43集｜再坏拦路 → 狼力挡下 → 逼近 Silas

**入口**：同坏态下一秒——伸手抓/围堵。  
**功能**：女主不可欺；为后文甩锅蓄势（他们仍觉「失控」）。  
**人物**：Ava、三子；（Bella 可远观 OS）

**节拍**  
1. 理由堆叠：预言、父亲、夜嚎需要她、不准嫁骗子。  
2. Ryan 先动手；Lucas 下令留下；Jason 跟拦。  
3. Ava 体内 Roman 狼力暴亮——挡下/反震，三子受伤但未死。  
4. Ava：你们永远学不会。让开。我去见 Silas。  
5. 三子又痛又恨又不敢死掐（药控+恐惧混）。  

**拉扯**：围攻↔狼力破围。  
**亮点**：赐力首度实战。  
**出口→44**：推开殿门/Silas 在座。

### 第44集｜银绑换真相

**入口**：见 Silas；银伤旧账与证词压力在空气里。  
**功能**：自愿上缚；交易感拉满。  
**人物**：Ava、Silas；（三子可殿外/后至）

**节拍**  
1. Ava 甩证词质问：十年前搞了什么鬼。  
2. Silas：想听全部真相，就甘愿被银武器捆绑。  
3. 多轮拉扯：Ava 疑→仍答应（要真相）。  
4. 银链/银铐上身，灼痛可见。Silas 眼露胜算。  

**亮点**：自愿入瓮。  
**出口→45**：缚死；Silas 开口。

**亮点**：恩人面具裂开。  
**出口→46**：还有更狠的。

### 第46集｜屠族 + 水牢 → 吐血痛哭

**入口**：Silas「你以为停战就完了？」  
**功能**：族灭与父母真相；情感顶格。  
**人物**：Ava、Silas

**节拍**  
1. 食言：停战后仍追杀白月；族人血流成河。  
2. Ava 震惊怒斥：说好不得追杀！  
3. Silas 毫无愧色：食言了，杀了。  
4. Ava 气急吐血。  
5. 父母在**深海水牢**日夜浸泡；「现在可以团聚了」。  
6. Ava 痛哭：以为他们好好活着……恩人是仇人。  

**拉扯**：质问↔无耻招供。  
**亮点**：恩人崩塌。  
**出口→47**：侍从上前要押送水牢。

### 第47集｜五卡：挣脱反打

**亮点/五卡**：入瓮者翻盘。

### 第48集｜伤父怒 → 打三子 → Bella 反捅

**入口**：三子看见父亲吐血，暴怒。  
**功能**：父仇戏；Bella 态度反转。  
**人物**：Ava、Silas、Lucas、Ryan、Jason、Bella

**节拍**  
1. 三子斥：你竟敢伤父亲！  
2. Ava：不仅是伤害——他残害我同族和父母，我要他的命！  
3. 交手，打伤三子（狼力仍在）。  
4. 三子向 Bella 求救（「Bella 帮我们！」）。  
5. Bella 反手**捅伤**他们；众震惊。  

**亮点**：求救者变捅刀人。  
**出口→49**：Bella 持刀/血刃，开口摊牌。

### 第49集｜身世 + 禁药总揭 + 嘲讽打脸 → Ryan 杀 Bella

**入口**：同场血泊；Bella 笑。  
**功能**：F02/F03 总收；甩锅打脸；Bella 死。  
**人物**：Ava、Bella、三子；（Silas 可瘫在旁）

**节拍（台词必须厚）**  
1. Bella：十二年前被 Silas 亲手驱逐；他已不认得长大的我。  
2. 两计划：先当 Luna 掌权再复仇；后见 Ava 要报仇，有意投靠。  
3. 承认：禁药控制你们（点项链，呼应 41–43）。  
4. 三子甩锅大爆发：「都是你害我们失去理智！我们本质不是那样！都是你控制我们才伤害 Ava！」  
5. **Bella 嘲讽打脸（多轮具体点名）**：灌药的手、毁戒的脚、烧衣的火、打脸的拳、逼割族徽的——**一件件是你们做的**；药只放大，动手的是你们；伪善面具撕碎；三子面红耳赤。  
6. Bella 向 Ava 投诚；Ava 尚在犹豫。  
7. **Ryan 咬牙刺死 Bella**，痛骂她。  

**亮点**：揭药+打脸+投诚死。  
**出口→50**：Bella 死；三子跪跌向 Ava。

### 第50集｜跪求被驳 → A+C 灭族 → 留三命 → 父母重逢

**入口**：跪求「原谅我们」。  
**功能**：预言兑现；Silas 死；重逢。  
**人物**：Ava、三子、Silas、Roman（殿内接）、Celeste+父

**节拍**  
1. Ava 冷驳：跪也没用；看见自己做过的事。  
2. **灭族视觉 A**：最大纯血狼魂+极寒能量波扫城，建筑崩裂。  
3. **C 尾闪光**：圣石残渣最后一声光裂/预言低语「覆灭」；**Silas 死于其中**。  
4. Ava 留三子命：当年你们杀到白月只剩三人（我与父母）；今天我也留三条命。  
5. 回狼王殿：父母已被 Roman 从水牢救出；久别重逢，含泪对白（细腻）。  
6. Roman：婚礼还等你。  

**亮点**：灭族镜像 + 重逢泪。  
**出口→51**：婚服/礼堂将起。
