## 五、分集落点（每集自带开场接法）

### 第24集
1. **开**=23 下一秒：爪改砸树，树倒。  
2. 不躲→战俘逻辑→承认不能杀→改囚禁。  
3. 巧逃：爪嵌树时折枝楔缝 + 镣铐反套树根，滚坡窜林。  
4. 浸银猎索缠腕颈、钉泥、膝压。  
5. **收**=索未解、人钉泥——交 25。

### 第25集
1. **开**=同地同索：加套嵌银狼筋骨铐，拽起押回。  
2. 路上假 Luna 饵。  
3. 狼魂+压制挣铐，伤 Silas，虚脱反方向再逃（同林道）。  
4. Bella（22–23 林线未撤）拦虚脱的 Ava，宣死期，凶器举起。  
5. **收**=凶器未落——交 26。

### 第26集
1. **开**=凶器将落：Ava 问诅咒 → Bella「巴不得覆灭」。  
2. 将刺→Silas 追上打晕 Bella→夺器。  
3. Ava 再逃→银矛钉掌入泥→封啸拖回城入古老岩监。  
4. 三子来路一句后入牢：「早知你会回来。」  
5. **收**=自恋落定；Bella 仍晕——交 27。

### 第27集
1. **开**=同牢自恋余韵；掌腕伤可见。  
2. Bella **带伤**入场，药+话术挑拨。  
3. 毁狼王戒 → 切 Roman 心痛出发。  
4. Ava 反击控诉→开脱→再自恋。  
5. **尾抛嫁衣来路**：「把她房里那套嫁骗子的衣服拿来」——箱角扔进或侍从应声。  
6. **收**=碎戒在+Roman 上路+嫁衣将至/已至——交 28。

### 第28集
1. **开**=同牢；碎戒未清；嫁衣在脚边。  
2. 挑拨→撕/烧嫁衣（婚契不毁）。  
3. 反击失败→开脱→再自恋。  
4. **收**=衣烬在+人虚——交 29。

### 第29集
1. **开**=同牢衣烬；Bella「衣没了不够」→银刑（惩罚口径）。  
2. 银具叠在旧伤上。  
3. 狼魂/压制崩半环→虚脱按回。  
4. **收**=银具仍勒+虚脱——交 30。

### 第30集｜三卡
1. **开**=银具未解；加码银雾/致死逼认（非净化）。  
2. 实濒死；无逃生。  
3. 圣石崩一大块；与心跳空拍剪接。  
4. Roman 远讯不救穿。  
5. **卡点**黑屏。
