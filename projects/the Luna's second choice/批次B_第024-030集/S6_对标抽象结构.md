## 四附、三子施虐成立理由（审核点7 · 铁律）

> **禁止**：Bella 空口「她坏 / 她恨你们 / 听我的」→ 三子立刻重虐。

### 理由公式（每轮虐前自检）

```text
【他们已知的硬恐惧】预言：Ava 离开/失控 → 夜嚎灭（F01，16 集已知）
+ 【本批刚发生的可见事实】伤父 / 圣石裂 / 私逃 / 拒回 / 反击王子
+ 【当场可见物证】戒 / 嫁衣 / 仍不屈服的态度
+ 【错结论】（Bella 帮腔钉死）毁掉物证/用疼留下 = 救族救她
(+ 禁药放大情绪，不替代上述三条)
→ 才允许虐件落地
```

### 第26集
1. **开**=凶器将落：Ava 问诅咒 → Bella「巴不得覆灭」。  
2. 将刺→Silas 追上打晕 Bella→夺器。

5. **收**=自恋落定；Bella 仍晕——交 27。

### 第27集｜理由①满档后才毁戒
1. **开**=同牢自恋余韵；掌腕伤可见。  
2. **先堆理由（必写满，见上表①）**：父伤展示/传报 + 圣石再裂传报 + 戒在指上特写；三子自己吵「预言/灭族/伤父」。  
3. Bella **带伤**入场：禁药微释；话术只**钉死错结论**（戒=灭族开关），不替代物证。  
4. 三子达成「必须毁掉这个」→ 毁狼王戒 → 切 Roman 心痛出发。  
5. Ava 反击控诉→三子用「你看她还护戒/还打我们」开脱 Bella→再自恋「毁了她就留下了」。  
6. **尾抛嫁衣来路**（为 28 物证）：「把她房里那套要嫁骗子的衣服拿来——看看她多认真。」  
7. **收**=碎戒在+Roman 上路+嫁衣将至——交 28。

### 第28集｜理由②嫁衣物证到位后才毁衣
1. **开**=同牢；碎戒未清；**嫁衣摊开在脚边**（抄家物证落地）。  
2. **先堆理由②**：婚期「还有几天」+ 嫁衣=私逃实锤；接 27 她护戒/反击=「心还在外面」。  
3. Bella 药+话术把嫁衣钉成「今晚不毁，明天她就嫁走、圣石塌」。  
4. 撕/烧嫁衣（婚契不毁）。  
5. 反击失败→开脱→再自恋「衣没了她没处嫁，只能留夜嚎」。  
6. **收**=衣烬在+人虚——交 29。

### 第29集｜理由③升级到银刑（仍非空口）
1. **开**=同牢衣烬；三子发现她仍不认输/仍控诉。  
2. **先堆理由③**：衣毁仍硬 → 解读为「骗子魂契还在」；可叠加圣石异响/父令「不许再逃」；她 25/27/28 连伤人被算成「攻击王子=攻击夜嚎」。  
3. Bella 怂恿银刑：口径=「用克星疼断她的外心 / 让她不敢再逃」——**惩罚与留下**，非净化。  
4. 银具叠旧伤；Ava 狼魂/压制崩半环→虚脱按回。  
5. **收**=银具仍勒+虚脱——交 30。

### 第30集｜三卡（理由④：失控加害）
1. **开**=银具未解；三子已被「她死不了/父亲要活口」与「必须当场断外心」撕扯。  
2. Bella 加码银雾至致死级（事故话术/逼认）；三子在药+灭族恐惧下误判「再加一点她就会听话」。
