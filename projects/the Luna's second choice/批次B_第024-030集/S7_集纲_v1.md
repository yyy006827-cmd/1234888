### 第24集｜爪改砸树 → 不能杀 → 巧逃 → 银索制伏

**入口（23→24）**：同一森林、同一姿势——爪在半空改道砸进脸旁树干，树轰然倒。  
**本集功能**：拆穿「不能杀」；改囚禁；巧逃爽拍；狠捕按回。  
**主场**：日/苍光·外·出城密林（倒树、木屑、潮泥、镣铐金属光）。  
**人物**：Ava、Silas；（Bella 远景可闪，不抢戏）

**第一幕·建立**  
爪入树、树倒、木屑扑脸。Silas 质问为何不躲。

**第二幕·升级**  
1. Ava 战俘逻辑：十年前能杀早杀；等到现在=不能杀。  
2. Silas 难堪暴怒：承认——杀则夜嚎受诅咒；但可**永远囚禁**。  
3. Ava 骂卑鄙，拒束手。  
4. **巧逃（无血洞）**：Silas 掏镣铐时爪/掌仍嵌树创——Ava 折枝楔进爪缝卡住半拍；抄起落地镣铐反套其另一腕与树根；滚坡窜林。（可辅极寒点冻铐环，不开大）  
5. Silas 半狼化追；**浸银猎索**甩中腕颈（银灼=克星，非疗），拖翻钉泥，膝压背，索收到难狼化。

**第三幕·钩子**  
人钉泥、索未解、Silas 压着——**动作未完**。  
**反击拍**：巧逃本身。  
**主视觉**：倒树卡爪 / 银索钉泥。  
**出口→25**：同地同索制伏态。  
**亮点≥8；反转**：杀意改囚禁；逃出又被索收回。

### 第25集｜加铐押回 → 召魂伤父 → 虚脱 → Bella 死期

**入口**：同地，猎索未松；Silas 就地加套**嵌银狼筋骨铐**，拽起押向夜嚎。  
**本集功能**：假 Luna 饵；过载召魂挣绑反击；死期钩。  
**主场**：密林→回城兽道（树影、银烫白烟、虚脱喘息）。  
**人物**：Ava、Silas、Bella（后半）

**第一幕·建立**  
骨铐勒腕；银烫叠旧索痕。Silas：乖乖回去仍可当未来 Luna。

**第二幕·升级**  
1. Ava 拒饵；挣则越烫。  
2. **反击拍（主）**：OMEGA 体强召纯血**狼魂** + 短促**血脉压制**——Silas 膝软半拍→骨铐崩→狼魂冲击伤其肩/胸（可见血）。  
3. 代价：吐黑血、腿软、虚脱；反方向再逃（同林道）。  
4. Silas 带伤追。Bella（22–23 林线未撤）抄近路拦住虚脱的 Ava。  
5. Bella 宣死期：Silas 不敢杀，她可以；凶器举起。

**第三幕·钩子**  
凶器将落、未刺入——定格。  
**主视觉**：骨铐崩裂白烟 / 狼魂撞父 / 匕影压喉。  
**出口→26**：同一林道、凶器未落。  
**信息差**：观众知 Bella 要死局；Silas 要活口，两线将撞。  
**亮点≥9；反转**：挣脱父权又跌进死期。

**人物**：Ava、Bella、Silas；后：Lucas、Ryan、Jason

**第一幕·建立**

**第二幕·升级**

4. 入**古老囚牢**：潮岩、锈环、灰光缝、霉苔铁腥、远感圣石裂息。  
5. Silas 丢入后一句「守住她」可交三子（若他离场）。

7. 三子见伤见链，大言：**「早就知道你会回来。」**（接 22 苦肉计自恋）

**第三幕·钩子**

**反击拍**：再逃未遂（被钉掌打断）。  
**主视觉**：银矛钉掌 / 岩监灰光 / 三子俯视自恋。  
**出口→27**：同牢自恋余韵；腕掌伤可见。  
**亮点≥9；反转**：被「救」成更惨的囚；「回来」是铐回来的。

**第一幕·建立（自恋）**

**第二幕·升级·理由堆叠（动手前必写满，缺一不可）**  
1. **伤父事实**：侍从/Silas 伤势传报或带血外袍一角——25 召魂所伤；三子震怒「你敢对 Alpha」。  
2. **圣石链**：再报异动/裂纹扩大（接 15/20）；Jason 灭族恐慌拉满。  
3. **预言恐惧**（他们 16 已知）：留下她=留命脉；再逃=灭族。  
4. **物证**：特写她指上**狼王戒**仍在——「还有几天」婚期没死心。  
5. Bella **带父击伤**入场：禁药微释；**指着戒**钉错结论「这就是灭族开关」——不替代上述物证。

9. **硬开脱**：三子挂事实「她还护戒！还打我们！父亲伤还在！」替 Bella/自己开脱。  
10. **再自恋**：「戒没了她就留下了。」  
11. **嫁衣来路（出口伏笔）**：下令抄她房里「要嫁骗子的那套衣服」——侍从应声/箱角扔进。

**主视觉**：戒碎溅污 / Roman 攥胸出门 / 囚牢灰光。  
**出口→28**：碎戒未清；嫁衣到场。

**第一幕·建立（自恋接棒）**

4. **预言+父令**：放任=送圣石、违收归。  
5. Bella 药+指衣：「她连衣服都备好了；今晚不毁，明天就嫁走。」  
6. 撕/烧嫁衣（火可起；Ava 极寒只能灭边角，**救不回衣**）。婚契不上场或不毁。  
7. **反击拍**：压制/抓伤/扑火失败；控诉双重标准。

**第三幕·卡点**

**情绪顶格**：为 Ava 窒息 + 为灭族预兆慌 + 恨三子/Bella 到顶点。
