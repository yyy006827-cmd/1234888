### 3. 信息释放节奏

- **观众领先**：恶女操控早被观众知道；本片段进一步给「罪证已被录下、将送达悔方」。
- **悔方滞后两拍**：先自欺 → 被旁证逼认「真要嫁」→ 仍不知药/全套真相；旧恩被父亲单方面灌输。
- **长辈半知**：知儿子混账、挺女主离场；未必知恶女全貌/禁药（对标片段未给禁药线）。
- **可借原则**：批次02可让「罪证/真相包裹」晚一点砸到三子，但**禁药总揭仍锁约第50集**；本批最多给 Lucas 级证据链推进，禁止三子因一条录像全醒。

### 4. 情绪曲线（抽象）

```text
自欺硬撑
  → 旁证砸脸
    → 否认伪证
      → 承认决裂
        → 占有欲暴起追人
          → 高位礼仪送行（女主扬眉）
            → 临别留雷（真相包裹）
              → 错身扑空
                → 父权羞辱跪罚
                  → 旧恩连环砸
                    → 悔意冒头（浅）
```

批次级一句话：**自欺破裂 → 送行降维 → 罪证埋雷 → 扑空 → 父权旧恩刑 → 浅悔。**

1. ❌ 集体定调「冷落她、绝不追、等她夹着尾巴爬回来」的口头禅组合（与批次01 S6 清单9同族，本批再禁）
