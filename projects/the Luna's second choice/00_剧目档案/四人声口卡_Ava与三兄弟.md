# 四人声口卡｜Ava × Lucas / Ryan / Jason

> 用途：全本台词「立人设 + 拉开三人」改稿时的唯一声口标准。  
> 依据：`S1_人物小传` + 用户审读意见（2026-08）。  
> 喂 AI 时：整页粘贴进提示词，先于任何分场正文。

---

## 0. 总审读意见（硬锁，先于个人声口）

1. **台词太中文**  
   - 禁：成语堆、骂战排比、国内狗血连珠炮、说明腔长句。  
   - 要：短、冲、能直接英译且不啰嗦；一句一事；配音一口气说完。  
   - 世界观硬词可留：Mate / Reject / Mark / Luna / Alpha（日常少整句中英硬夹）。

2. **三兄弟性格略重叠 → 必须再拉开**  
   - 抹掉名字后仍听不出是谁 = 失败，整场重写。  
   - Lucas ≠ Ryan ≠ Jason：功能、句式、音量三条同时不同。

3. **禁止「一人一句硬加情绪」**（旧写法死刑）  
   - 错误示范：三人都骂 Ava「你太过分了／你伤害 Bella／你不配」——同一信息说三遍，像一群人围吵，节奏拖死，英译更啰嗦。  
   - **正确规则（三人同场铁律）**：  
     - **只保留一个信息点**（事实／指控／要求只出现一次）。  
     - **信息点由主导者说**（多数场次 = Ryan 开火 或 Lucas 收口定调）。  
     - **另外两人禁止复述信息**，只做态度区分：  
       - 威胁／动手（Ryan）  
       - 压场／定性／假仁义（Lucas）  
       - 跟队半句／幼态甩锅（Jason）  
     - 能用动作代替的第二、第三句，删台词，改 △。

4. **节奏：简洁优先**  
   - 三人围 Ava：目标 **总对白行数砍到原篇幅 50%～60%**。  
   - 单人单轮台词：**中文优先 ≤12 字；超过 20 字必须有戏的理由**。  
   - Ava 反击：一句刺穿，不跟他们开辩论赛。

5. **英译友好自检**  
   - 写完中文后脑内英译：若变成三句同义复读（You hurt Bella / How could you / You’re wrong）= 重写。  
   - 好成：One accusation + one threat + one tag-along。

## 1. 三人同场「话轮公式」（改稿必用）

```
【本场只准 1 个信息点】→ 写在卡片上
【主导者】说出该信息（1 句）
【第二人】态度/功能句（不重复信息，≤1 句）
【第三人】跟队半句或纯动作（可无台词）
【Ava】反杀 1 句（举证/拒绝/嘲，不解释人生）
（可选）Lucas 收场 1 句压人 —— 仅当本场需要「假权威」
```

### 谁当主导者？

| 场面类型 | 主导 | 第二 | 第三 |
|---|---|---|---|
| 护 Bella、动手、暴怒 | **Ryan** | Jason 跟 | Lucas 压场/假仁义收尾 |
| 质问、给面子、逼认、悔后自欺 | **Lucas** | Ryan 威胁补刀 | Jason 附和 |
| 三人意见不一时 | Lucas 定调 或 Ryan 打断；**Jason 绝不带头定新罪名** | — | — |
| Ava 已占上风／心死反击 | **Ava** 定调；三人只准反应，不准三人轮流喊冤 | — | — |

## 2. 分角色声口（硬规则）

### Ava｜冷、短、反问杀

| 项 | 内容 |
|---|---|
| 一句话人设 | 真善美但不圣母；先证据后拳头；心死不回头 |
| 句式 | 短句、反问、举证、冷嘲；少形容词 |
| 音量 | 中低——越气越冷，不跟他们比嗓门 |
| 对三兄弟 | 不求、不解释「我们曾经多好」；只点具体罪 |
| 对 Roman | 可松半拍、可开玩笑（本卡改稿范围外可另标） |
| 禁用 | 长篇自白、跟三人逐条辩论、国内偶像剧哭腔劝回头 |
| 示范（好） | 「道歉有用？」「匕首在这儿。」「我本来也没想选你们。」 |
| 示范（坏） | 「你们难道不知道这十年我为你们付出了多少吗？」（太中文、太啰嗦、英译必拖） |

**阶段差（只调温度，不调人设）：**  
药控期：犀利举证 → 逼婚囚禁：更冷、更短 → 火葬场：可恨可讽，**永不心软回头**。

---

### Lucas｜沉、判、压场（唯一会起疑的人）

| 项 | 内容 |
|---|---|
| 一句话人设 | 长兄、假成熟、爱定性；会闪悔，又最快自欺按回 |
| 句式 | 判断句、质问句；话少，一句比一句沉 |
| 音量 | 低于 Ryan；靠「定性」吓人，不靠吼 |
| 功能位 | 定调／收场／给面子／逼认；悔时可以抖，但忌无差别崩盘喊叫 |
| 信息点角色 | 常当「定性信息」的主人：「够了」「你戏演完了」「我是给你面子」 |
| 禁用 | 跟 Ryan 同步咆哮；「我命令你」空威权；主动发明跟 Ryan 同义的第三遍指控 |
| 示范（好） | 「你戏演够了吗？」「我是在给你面子。」「……还有疑点。」（起疑时） |
| 示范（坏） | 「Ava 你太过分了 Bella 那么可怜你怎么能这样对她！」（信息复读 + 太中文） |

**后悔流（真相前铁律）：** 打压 → 闪悔（可维护 Ava 半拍）→ 自欺「都是 Ava 的错」→ 再打压。禁止写成持续觉醒。

---

### Ryan｜吼、威胁、先动手（信息点火者）

| 项 | 内容 |
|---|---|
| 一句话人设 | 肌肉暴烈、下半身思考；护 Bella 第一；最狠也最后悔最极端 |
| 句式 | 咆哮短句、威胁、点名动手；几乎不讲理 |
| 音量 | 全场最高 |
| 功能位 | **开火**——多数围攻场由他说出唯一信息点 |
| 第二人时 | 只加威胁／扑人，不复述 Lucas 刚说完的理 |
| 禁用 | 先讲道理；先于 Lucas 起疑禁药；阴谋长句；温柔劝说 |
| 示范（好） | 「你再咬 Bella 一句，我撕了你的嗓子。」「收起你的把戏。」 |
| 示范（坏） | 「你怎么可以这样对待 Bella，她那么善良，我们不能允许……」（啰嗦、英译必肥） |

---

### Jason｜跟、半句、幼态（永不带头）

| 项 | 内容 |
|---|---|
| 一句话人设 | 跟风党；谁声大听谁；伤害最轻；单独见 Ava 最先软 |
| 句式 | 「没错／就是／太恶心了」+ 半句；语气词可有，信息点不可有 |
| 音量 | 中或偏尖，但短 |
| 功能位 | **跟队标签**；可用动作（点头、挡人、后退）代替台词 |
| 铁律 | **禁止**开新罪名、禁止复述完整指控、禁止三人里话最多 |
| 示范（好） | 「没错。」「就是她！」「……恶心。」 |
| 示范（坏） | 「Ava 你真的太过分了你知不知道 Bella 为我们做了什么！」（与另两人重叠） |

## 3. 对比尺（写完必过）

| 测试 | 通过标准 |
|---|---|
| 换名测试 | 遮住名字，仍能标出 Lucas / Ryan / Jason / Ava |
| 信息点测试 | 三人场只有 **1** 个事实/指控/要求；另两人是态度不是复读 |
| 中文腔测试 | 无成语堆、无围吵排比、无「难道……吗」连发 |

## 4. 改写对照（同一信息点）

**信息点：** Ava 诬赖／伤害了 Bella。

| 旧（死刑） | 新（合格） |
|---|---|
| Ryan：你太过分了！你怎么能诬赖 Bella！ | Ryan：再咬 Bella——我撕了你。 |
| Lucas：Ava，Bella 那么可怜，你不该这样对她！ | Lucas：够了。别演了。 |
| Jason：就是！你太过分了！Bella 什么都没做错！ | Jason：没错。 |
| Ava：你们根本不听我解释…… | Ava：刀在这儿。谁爱信谁信。 |

→ 信息只出现一次（Ryan 开火）；Lucas 定性；Jason 跟队；Ava 举证收刀。围吵感消失，英译也短。

## 6. 与 S1 红线对齐（改词不得破）

- Ava：拒三兄弟后永不回头；不哀求施害者。  
- Lucas：真相前保留起疑与悔循环；不纯暴工具人。  
- Ryan：不先于 Lucas 察觉禁药；揭药前色令智昏可被按回。  
- Jason：无独立坏主意；伤害最轻；悔后不硬气。  
- 禁药：放大器不是遥控器（人设逻辑，台词勿写成「他们被完全遥控」）。
