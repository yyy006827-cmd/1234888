# S2 · 世界文化观（《The Luna's Second Choice》）

> 状态：已产出，待用户审核
> 依据：S0 一卡剧本 + S1 人物小传 + 用户补充（北美地区狼人世界观；短剧狼人风格，更灵活）
> 用途：锁定规则 / 阶层 / 禁忌 / 超能边界；续写中出现的一切能力、制度、道具不得越界。

---

## 总调性（先锁死）

本剧采用**北美短剧狼人（ReelShort / DramaBox 同题材）**的灵活世界观，而非硬核都市奇幻：

- 狼人社会与现代人类世界**平行共存、大体互不干涉**——故事几乎全在狼族内部展开，不必解释给人类保密的复杂机关。
- 术语直给、仪式可视化、能力为戏剧服务：**看得懂、打得响、反转够快**优先于设定自洽的学术感。
- 规则有弹性空间，但**一卡已出现的机制不得自相矛盾**；需要新设定时，必须能挂在本档案的四大板块下，禁止为圆情节临时开挂。

## 1.【规则】

### R01 · Fated Mate / Mark / Reject（命定伴侣机制）

- **内容**：狼人可感知 Mate 气味；成年典礼上可 Mark（认伴侣）；也可 Reject（拒绝）。Reject 仪式可当众完成，粉线断裂并释放能量冲击（第 10–13 集）。月神可应狼魂召唤，更改 Fated Mate 并结成魂契（第 1–2 集）。
- **出处**：第 1、2、10–13 集。
- **违反代价**：强制 Mark 无效；被 Reject 者承受能量反噬（吐血、摔飞）；擅自改命要付代价（见 R05）。
- **短剧灵活点**：Mate 线可被可视化（粉线从心脏射出）；气味可被旁人闻到；魂契高于普通 Mate，禁药无法伪造（第 10 集失灵）。

### R02 · 继承与联姻（选谁谁继任 Alpha）

- **内容**：Silas 指定——Ava 18 岁从三子中选夫，选中者成为下一任 Alpha（第 2 集）。目的是"收归己用"。
- **出处**：第 2、11、12 集。
- **违反代价**：Reject 后继承权真空，狼群权力结构动摇；Silas 布局崩塌。
- **短剧灵活点**：继承规则可因 Alpha 宣布而成立，不必走复杂议会程序；后续可用"继承权争夺/指定新候选人"制造冲突。

### R03 · 大祭司预言与诅咒约束

- **内容**：预言 Ava 将覆灭夜嚎狼群；**不可杀、不可虐待**她，否则夜嚎遭诅咒；只能收归己用（第 2、12 集）。
- **出处**：第 2 集闪回、第 12 集 Silas 回忆。
- **违反代价**：诅咒（具体形态续写可发挥，但必须严重到足以拴住 Silas——灭族级威胁）。
- **短剧灵活点**：诅咒是"软镣铐"戏剧装置，不必提前写死诅咒细节；**Silas 任何直接杀/虐动作都禁止**，他的恶只能走软刀子（羞辱、联姻强制、名誉构陷、借刀）。

### R04 · 银器克狼

- **内容**：纯银是狼人克星；竞技场禁银；银匕首可致命（第 1 集）。
- **出处**：第 1 集。
- **违反代价**：银器入体可致重伤/濒死。
- **短剧灵活点**：银 = 通用弱点，续写可作暗器、陷阱、刑具；不必引入其他金属体系。

### R05 · 改命代价（狼力削弱）

- **内容**：召唤月神更改 Fated Mate 后，Ava 狼力削弱一个月，体能等同 OMEGA（第 2 集）；期间强召纯血本体会反噬（第 6–7 集吐黑血、濒死）。
- **出处**：第 2、6、7 集。
- **违反代价**：过载 = 重伤甚至死亡；Roman 可疗伤、可被召唤救援（第 9 集）。
- **短剧灵活点**：一个月期满 = 明确的战力反转节点；期满后能力回归，但不可无代价地无限开大。

### R06 · 禁药规则（放大之恶，非降智遥控）

- **内容**：Bella 持有**仅对三兄弟定制**的禁药（心形项链机关释放幽蓝气息）；作用是**放大狼人情绪 / 人性之恶**，使其更易攻击 Ava、偏袒 Bella；**不是**一闻就失智听话。
- **出处**：第 1、3、5、7、9、10 集 + 用户设定。
- **违反代价 / 失控空间**：药效有起伏、可被质疑打断（Lucas 起疑）；放大后的情绪可能反噬操控者（失控时 Bella 必须加新手段）。
- **短剧灵活点**：禁药可视、可闻、可针对特定人；续写禁止写成"心灵控制 / 完全夺舍"；真相揭露前三兄弟不知自己中药。

### R07 · 魂契至高

- **内容**：月神牵线的魂契高于普通 Mate；匹配狼魂罕见（Roman 百年一遇）；魂契双方有心灵感应（第 7 集）。
- **出处**：第 1、2、4、7、9 集。
- **违反代价**：强行拆魂契 = 对月神不敬（续写若需要，可作重大仪式/代价事件）；禁药无法覆盖魂契信号。
- **短剧灵活点**：感应可在危机时触发，但不可变成 24 小时监控（保留戏剧张力）。

### R08 · 竞技与荣誉规则（可灵活调用）

- **内容**：狼族竞技场决斗：无纯银、无外力，只有尖牙与利爪（第 1 集）。狼群重视公开场合的面子、Mate 宣誓、成人礼。
- **出处**：第 1、10–12 集。
- **违反代价**：使用禁武 = 耻辱/可被追究；当众出轨指控 = 狼群级名誉危机。
- **短剧灵活点**：荣誉规则是打脸舞台，不必写成严密法典。

## 2.【阶层】

从高到低（狼族内部）：

| 层级 | 称呼 | 本剧人物 | 说明 |
|------|------|----------|------|
| 0 | Lycan King（古老狼王） | Roman | 碾压一切狼群与狼人；不隶属任何单狼群 |
| 1 | Alpha（狼群首领） | Silas；终局 Ava | 一狼群最高权力；可指定继承、颁布联姻 |
| 2 | Alpha 血脉（王子/公主） | Lucas / Ryan / Jason；Ava（白月公主身份） | 继承人候选；纯血公主在血脉上可压制普通狼人 |
| 3 | Luna（Alpha 伴侣） | （争夺中：Bella 觊觎） | 名分+权力；Bella 的表层目标 |
| 4 | 祭司 / 功能精英 | 大祭司、巫师 | 预言、治疗、仪式；政治中立或依附 Alpha |
| 5 | 普通战士 / 族人 | 宾客、女仆、竞技场观众 | 群像；"观众嘴替" |
| 6 | OMEGA | Wilder；Ava 削弱期的临时体能标签 | 底层；可被鄙视、驱逐；**短剧里 OMEGA 更多是地位标签，不必展开复杂生理设定** |
| 7 | 被驱逐的流浪狼 | Bella（出身） | 人人喊打；无庇护、无领地 |

### 阶层流动：通道与障碍（冲突发动机）

- **上行通道**：联姻成为 Luna；继承成为 Alpha；月神/魂契跨越阶层（Ava→Roman）；战功与血脉压制。
- **下行通道**：Reject、驱逐、名誉构陷（Wilder 戏）、战败吞并（白月→夜嚎）。
- **核心障碍**：
  1. 预言诅咒拴住 Silas（不能用最简单的"杀掉威胁"）；
  2. 禁药制造的虚假情感秩序（三兄弟站 Bella）；
  3. 血统优越 vs 流浪出身（Ava 纯血 vs Bella 被驱逐）；
  4. Lycan King 超然于狼群政治——Roman 降维打击时，Silas 的 Alpha 权威不够用。

## 3.【禁忌】

### 狼族内禁忌

| 禁忌 | 后果 | 出处/用途 |
|------|------|-----------|
| 杀害 / 虐待被预言保护的 Ava | 夜嚎遭诅咒 | R03；Silas 的镣铐 |
| 竞技使用银器 | 犯规、可致命、名誉尽失 | 第 1 集 |
| 滥用禁药（狼族禁用） | 一旦曝光 = 死罪级丑闻 | 用户设定 + 第 1 集 OS |
| 背弃成人礼 / Mate 宣誓的公开羞辱 | 狼群级面子危机 | 第 10–13 集 |
| 驱逐后再潜回夺权 | 被揭穿则人人得而诛之 | Bella 暗线 |
| 强召超规格能力无视代价 | 反噬重伤/死亡 | 第 6–7 集 |

### 北美短剧市场 / 平台文化提醒

- **未成年**：核心角色已全部设定 18+；闪回幼年戏只做背景，不涉性暗示。
- **非自愿 / 羞辱戏分寸**：撕裙、当众羞辱等一卡已有桥段，续写可有张力但**避免过度露骨性暴力描写**；重点放在情感背叛与权力羞辱，而非猎奇。
- **多男围绕女主**：后悔流可吃醋可跪，但主 CP（Ava–Roman）甜宠干净；三兄弟追妻不得写成女主摇摆。
- **复仇尺度**：覆灭狼群、以命抵罪可以狠，避免无意义虐杀无辜平民的审美疲劳。
- **种族/物种比喻**：狼人阶层戏是幻想设定，对白避免滑向现实种族歧视话术。

## 4.【科技 / 超能边界】

### 存在的能力（一卡已立 + 允许的灵活延伸）

| 能力 | 上限 | 代价/限制 |
|------|------|-----------|
| 狼化 / 半狼化（爪、毛、瞳色、獠牙） | 战斗形态；声波震慑 | 普通狼人可被纯血压制 |
| 纯血血脉压制 | 气场逼跪、声波掀顶 | Ava 专属优势；削弱期大减 |
| 金狼本体（纯血完整化形） | 高爆发战斗 | 削弱期强召 = 反噬吐黑血 |
| 极寒寒气 / 冰封 | 灭火、冰封数人 | 耗能巨大，用完会倒下（第 7–8 集） |
| 掌心火焰（Lucas） | 远程火团、焚物 | 一卡已有；非无限火海 |
| 狼魂外化 | 召月神、匹配魂契、展示威压 | 挖出狼魂剧痛；改命有削弱期 |
| 月神显灵 | 改 Fated Mate、赐魂契 | 不可当万能许愿机；一剧内少用 |
| 魂契心灵感应 | 感知 Mate 危机 | 非实时监控；危机触发 |
| 狼王疗伤（紫光注入） | 可救濒死 | Roman 专属；不能治愈"被 Reject 的命运" |
| 禁药（情绪放大） | 仅对三兄弟；可被质疑打断 | 见 R06 |
| 巫师治疗 | 救回银伤濒死 | 功能位；非战斗单位 |

### 明确"不存在 / 不可能"（续写禁开挂清单）

1. ❌ 时间倒流、复活死者、抹除记忆的一键神技
2. ❌ 禁药变成完全夺舍 / 永久洗脑
3. ❌ 人类科技枪械主导狼人战争（本剧战场在爪牙与血脉）
4. ❌ 随意新增与一卡无关的种族（吸血鬼、女巫议会等）来抢戏——除非用户明确要求
5. ❌ Ava 在削弱期内无代价开大却不受伤
6. ❌ Roman 被普通狼人正面击败
7. ❌ Silas 直接下令处死 Ava 且无诅咒后果
8. ❌ 三兄弟在真相前"靠爱突然醒悟"而绕过禁药线
9. ❌ 用现代手机验毒、DNA 鉴定等把短剧写成刑侦剧（可用巫师/祭司/狼魂感应等世界内手段）

### 灵活空间（允许，但需挂靠本档案）

- 可为夜嚎 / 白月设计 1–2 个标志性场景（老宅大殿、竞技场、战利品仓库、悬崖海边、狼王城堡——一卡已有，优先复用）。
- 可给次要狼群、流浪狼聚落作背景板，服务复仇与覆灭线。
- 可在后期揭示 Bella 背后故事、诅咒的具体形态、白月狼群残存力量——但不得推翻 R01–R07。
