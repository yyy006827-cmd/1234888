# 《The Pureblood Luna's Awakening》50集｜「海外口语化」中文台词问题清单

> 口径：**改的是中文怎么说**，不是译成英文。  
> 目标：短、冲、能配音、像人物嘴里说出来的话；少小说腔、少成语堆、少中英硬夹、少口号悔。  
> 世界观硬词可留：Mate / Reject / Mark / Luna / Alpha / Omega / Lycan（首次出现可括注，日常对话少整句中英混说）

---

## 怎么判断「不像海外口语化中文」

| 类型 | 特征 | 处理 |
|------|------|------|
| A 中英硬夹 | God/NOW/FUCK/Babe/Wait 当句内口头禅乱插 | 改成中文语气词，或整句都用英文词但不混半句 |
| B 翻译腔 | 「这种不忠诚的感情」「真的很…」「道德绑架」像直译 | 换成中国观众也顺、配音也顺的短句 |
| C 小说/成语腔 | 昭告全族、做牛做马、狼性之恶、心灵感应 | 改成具体动作或白话 |
| D 口号悔/空悔 | 十年感情、唯一的光、本质不是坏人 | 改成认具体罪或求具体结果 |
| E 说教总结 | 「你心里有气，账算她头上」 | 改成人物会说的抢话 |
| F 降智硬刚 | 「狼王算什么」在狼王门口喊 | 改成自欺但不蠢 |

## 分集标注（原句 → 问题 → 中文改法）

### 第一集

**1. 巫师**  
原：`再晚一秒，月神也救不了她！`  
问题：空喊网感，不像急救现场。  
改：`快放下。银快顶到心了——我现在还能止血。`

**2. Ryan / Lucas（多处）**  
原：`我不准你污蔑她` / `你再污蔑 Bella，我就吃了你！`  
问题：「污蔑」偏书面。  
改：`不准你血口喷人！` / `你再咬 Bella 一句，我撕了你的嗓子。`

**3. Bella OS**  
原：`WOW，针对他们三个定制的禁药真管用，真的可以放大狼性之恶`  
问题：中英硬夹 + 「狼性之恶」小说腔。  
改：`呵，这药真灵。专治他们三个——专把他们心里那点脏放大。`

**4. Jason**  
原：`伪造证据？你真的很无耻！`  
问题：「真的很」翻译腔。  
改：`伪造证据？脸呢？`

**5. Ava**  
原：`这种不忠诚的感情，我不要！我要召唤月神 Reject（拒绝）你`  
问题：抽象翻译腔 + 中英说明腔。  
改：`十年，换来你们一次次护她。够了。我拒绝你们——现在。`  
（仪式句可另起：`月神在上，我拒绝他们。`）

**6. Ava**  
原：`十年的感情抵不过 Bella 的一个月，那就...不要也罢！`  
问题：像旁白总结。  
改：`十年抵不过她一个月？行。那就到此为止。`

---

### 第二集

**7. 大祭司**  
原：`Stop！杀了她，夜嚎狼群会被诅咒`  
问题：中英硬夹。  
改：`住手！杀了她，夜嚎会被诅咒——只能收着用。`

**8. Lucas**  
原：`NOW，告诉我，你把 Fated Mate 改成谁了！`  
问题：NOW 硬插。  
改：`说！你把命定对象改成谁了！`

**9. Ava**  
原：`难道我注定要和他们绑在一起吗？`  
问题：小说独白感。  
改：`我偏不跟他们绑死。`

---

### 第三–七集（中英口头禅高频区）

原则：**Babe / God / Wait / Really / Please / NOW / FUCK** 不要当逗号用。

| 原 | 改 |
|----|----|
| `God，那边有人溺水了。` | `那边有人淹着了！` |
| `Babe，谢谢你们相信我~` | `谢谢你们信我……`（可保留一次 Babe，别句句 Babe） |
| `Lucas，Please...` | `Lucas，求你……` |
| `NOW，就算被反噬……` | `哪怕反噬——我也要把本体召出来！` |
| `Really？你确定你的狼魂可以 Mark 她？` | `你确定？你的狼魂真能 Mark 她？` |
| `是心灵感应...FUCK，Ava 有危险！` | `是感应——操，Ava 出事了！` |
| `满地找狼牙` | `打到她满地找牙` |

**Roman 第七集**  
原：`我感到有一团火在灼烧...是心灵感应...FUCK，Ava 有危险！`  
改：`胸口像烧着——感应。操，Ava 有危险！`

---

### 第八集

**10. Ava**  
原：`FUCK YOU！我差点死了！`  
问题：只爆粗，没打回对方的「一点火」。  
改：`去你的。一点火？你差点把我活活烧死。`

**11. Lucas**  
原：`God，原来是它！Ava，对不起...我忘了，我道歉...`  
改：`……是那件袍子。Ava，对不起。我忘了。我错了。`

---

### 第九–十三集

把 `FUCK！我们刚刚差点被 Ava 害死了` → `靠！她差点弄死我们！`  
`Babe，我听见你在喊我的名字` → `你刚才喊我？想我了？`  
`Wait！Wait！Ava，不管发生什么，你必须嫁给我的儿子！` → `慢着！Ava，无论如何，你都得嫁给我儿子！`  
`自己脏，还污蔑 Bella` → `自己脏，还咬 Bella`

---

### 第十七–十九集

**12. Lucas**  
原：`才散步谣言说要嫁给那个骗子的？`  
问题：错词。  
改：`才散布谣言说要嫁给那个骗子？`

**13. Ryan**  
原：`我们只是犯了所有公狼都会犯的错误，这有什么错。`  
问题：像给出轨开脱的「雄性共同体」套话，海外也不吃。  
改：`男人都会看错人——但这不是我推开你的理由。我知道。`  
（若要保留自私：`我就是馋了，怎么了？`——更人物，但也更讨厌，可选）

**14. Lucas**  
原：`我是在给你面子，如果你继续装的话，我就不得不拆穿你了！`  
问题：「给你面子」大陆职场/江湖腔，不像狼族王子口语。  
改：`我已经留余地了。你再装，我就当众揭穿。`

**15. 苦肉计（多处）**  
原：`这就是她的苦肉计`  
问题：成语梗，配音别扭。  
改：`她又在扮可怜钓鱼呢。` / `又是那套装受伤钓同情。`

### 第三十集

**16. Lucas**  
原：`Ava，我们现在救你，你听话一点，配合我们。`  
问题：施害者「救人」说得像医护指导，假。  
改：`别挣了。Bella 说这药能保命——喝。`

### 第三十五–三十八集（甩锅与求和）

**17. Mira**  
原：`你平平无奇……凭什么你就能嫁给 Roman？`  
问题：梗概式雌竞。  
改：`我守了他多少年，他看都不看我。你一来，他亲自抱你进寝殿，还叫你狼后。`

**18. Jason**  
原：`我们本质不是那样的人！`  
问题：书面甩锅。  
改：`Bella 下了药。可动手的是我们——我知道一句“被利用”不够。`

**19. Jason**  
原：`看在我们十年感情的份上，就原谅我们吧……我们真的知道错了……`  
问题：求饶套话。  
改：`Ava，求你。别用看死人的眼神看我们。我们错了——错在动手，不只是错信 Bella。`

**20. Ryan**  
原：`你心里有气，尽管把账算在她头上，别把气撒我们身上。`  
问题：说教总结腔。  
改：`真正害你的人我们去抓。你干吗还咬我们不放？`

**21. Ryan**  
原：`狼王算什么，你要明白我们十年的感情才是最重要。`  
问题：在狼王地盘降智硬刚 + 口号。  
改：`一个新契约，抹不掉我们十年。你心里有数。`

**22. Ryan**  
原：`Ava 放不下跟我们十年的感情！`  
改：`看吧，她还是放不下我们。`

### 第四十一集

**23. Ryan**  
原：`你该牺牲自己守护它！`  
问题：「你该」说教。  
改：`夜嚎养了你十年。现在它要塌了——你得留下。`

### 第四十五–四十八集

**24. Bella**  
`God……Silas 怎么会死了` → `天啊……Silas 怎么会死……`  
`别担心，Babe，有我呢~` → 可留一次 Babe；或 `别怕，有我在。`

**25. Jason**  
原：`我们还能悔改，请你相信我们！`  
改：`我们还能改。你再看我们一眼——求你。`

**26. Lucas**  
原：`我们愿意做牛做马，愿意当众认罪，愿意把 Bella 的骗局昭告全族`  
问题：成语堆 + 古风。  
改：`你要我们跪，我们跪。你要我们当众认，我们认。你要我们把 Bella 的骗局捅出去，我们捅。`

**27. △不是台词但常和台词混排**  
`心无波澜`（48/49）→ 删，改动作：`Ava 没看他们，把目光投向殿外。`

---

### 第四十九–五十集（婚礼）

**28. Ryan**  
原：`你不能假装我们十年的感情不存在！`  
改：`别装十年没发生过！看着我们！`

**29. Jason**  
原：`你是我们唯一的光……没有你我们真的会散……`  
问题：偶像剧腔。  
改：`我们什么都没了。只剩你。你走了，我们就完了。`

**30. Lucas**  
原：`我们真的知错了。`  
改：`这次不怪 Bella。怪我们。字字算在我们头上。`

**31. Ava**  
原：`你们想用 Ryan 的命来道德绑架我，真的让人恶心！`  
问题：「道德绑架」「真的让」偏评论腔。  
改：`拿命逼我回头——恶心。那不叫悔，叫绑。`

**32. Ava（可加强钉死）**  
补一句更口语：`我不原谅。不回头。死也没用。`

## 建议保留、不必硬改的

1. **仪式台词**：`月神在上，我以狼魂之名……` / 求婚宣誓——可以略正式，这是典礼。  
2. **世界观词**：Mate、Reject、Mark、Luna、Alpha——专有名词，可留；避免「我要 Reject（拒绝）你」这种「英文+括注讲解」口播感，改成「我拒绝你们」或字幕释义。  
3. **Bella 偶发 Babe**：人设甜毒可以，但别每句 Babe。  
4. **Ryan 偶发脏话**：符合暴烈人设；Lucas/Roman 少用。
