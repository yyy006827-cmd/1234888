## 1. 写作规格（吃透后必须对齐）

对照用户手写 1–23，续写必须长这样：

| 项 | 规格 |
|----|------|
| 版式 | `第X集` → `场号 日/夜 外/内 地点` → `人物：` → `△` 动作 → `角色：对白` → `OS` / `【闪回】` / `【闪出】接` / `【字幕】` |
| 单集体量 | 常见约 **700–1600 字**；有戏的集（如 1、6、8）可更厚；禁止写成提纲压缩稿 |
| 对白密度 | **多轮拉扯**；中英混杂（God / Please / Wait / Fuck / NOW）；括号标情绪 |
| 动作 | △ 写清可见动作与镜头感，一步一步，不堆文学比喻 |
| 闪回 | 用本剧已出场场次编号（如 6-2、7-1、2-3），短切 |
| 上下集 | 下一集开场必须接上一集末句/末动作（例：22 尾「秘密到底是什么」→ 23 首句同句） |
