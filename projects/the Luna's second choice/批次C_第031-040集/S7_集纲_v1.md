## 一、本批故事一句话

三卡假死当夜 Roman 破牢救美、代罚三子、抱走 Ava；Silas 见圣石全碎后闻人走而昏。三子认定 Bella 害死 Ava→**先抓 Bella 扑空、有限醒悟**→**再哭丧怀念**；Silas 揭她还活，三子自信上门道歉就能抢回。城堡女仆 Mira 因妒害 Ava，恰被三子撞见并讨好式教训；Ava 讽刺甩锅。三子把讽刺当台阶，Roman 亮出十年前战事证词——四卡。

### 第31集｜破牢救美 → 代罚 → 抱走 → 圣石前昏厥

**入口（30→31）**：古老地下囚牢——地动未停；Ava 闭眼垂手；Lucas 手中/眼前银屑药；「不准死」余音未落。  
**本集功能**：Roman 抵达兑现；英雄救美；代女主罚三子；抱离；Silas 碎石线；Bella 趁乱逃（侧写）。  
**主场**：日内·古老地下囚牢 → 日外·祭祀广场（碎石）。  
**人物**：Roman、Ava、Lucas、Ryan、Jason、Bella（逃影/空镜）、Silas；可有侍从惊呼

**第一幕·建立**  
地动中牢门/石壁崩裂感；三子围假死身；Lucas 仍盯银屑。威压先至——**Roman 破入**（紫金狼威/人形亦可）。

**第二幕·升级**  
1. Roman 一眼看穿银伤、假死、囚牢——当场罪证满档。  
2. **代罚**：不杀；可摔砸、跪压、狼威镇压、当众断其嚣张（Ryan 最先扑最先挨）。对白少而狠：伤我的 Mate，罚你们。  
3. Lucas 或喊「药有银/Bella——」——乱局未审完；药瓶可被碰落/Roman 收走一拍（为33醒悟留物证链，勿在本集审完禁药）。  
4. Roman 抱起 Ava（动作轻、眼神冷对三子）。  
5. **侧写 Bella 逃**：乱中心形项链影/侧廊人影窜出/后门开合——观众知她跑，三子本集可未追。  
6. 转场：Silas 冲到祭祀广场，看见圣石**全碎**一地，急得发抖：人明明关牢里，为何还碎？想不通。  
7. 三子带伤跑来报：Ava 被那个骗子 Roman 带走了！  
8. Silas 震惊、不敢置信，嚷「夜嚎狼群要完了」——**晕厥**。

**第三幕·钩子**  
Silas 倒在碎石前；人已被抱走的事实钉死。  
**反击拍**：Roman 代罚=女主欠债由 Mate 当面讨。  
**主视觉**：破牢狼威 / 抱走剪影 / 碎石堆前昏厥。  
**出口→32**：Roman 抱 Ava 离夜嚎；Silas 昏；三子惊魂。  
**亮点**：救美+代罚+碎石恐慌三线同集；反转：关牢「万无一失」仍碎→人还被狼王拿走。

### 第32集｜城堡疗伤未醒 → Mira 恨视 → 认定 Bella 害死 → 出门抓人

**入口**：狼王城堡——Roman 将昏迷 Ava 安置卧榻；银伤可见；Theo 候命。  
**本集功能**：疗伤但不醒；Mira 立恨；夜嚎侧**先定性凶手**并启动抓捕——**本集不哭丧**。  
**主场**：日内·狼王城堡 Ava 卧房；转场日内·夜嚎（囚牢余场/议事廊）。  
**人物**：Roman、Ava（昏迷）、Theo、Mira；Lucas、Ryan、Jason

**第一幕·建立**  
Roman 以狼王力量/魂契稳息+清创包扎（**禁银疗**）。Theo：还需几个时辰才能醒。Roman 嘱妥帖照料后暂时离开（族务/清敌踪/取药皆可，一句带过）。

**第二幕·升级**  
1. Mira 入房「服侍」；至床前，恨意盯昏迷的 Ava。  
2. 台词锁定身份危机：你平平无奇，跟我一样也是 OMEGA，凭什么你就能嫁给 Roman。  
3. 可伸手欲碰颈/被门响收回——恨种立住，本集未必下手（留给37）。  
4. **转场夜嚎**：三子惊魂未定，复盘牢中——Ava「死了」、药有银屑、药是 Bella 给的。  
5. **定性**：就是 Bella 害死了 Ava。怒大于悲；Lucas 提银屑，Ryan 要撕了 Bella，Jason 跟吼。  
6. **出门抓 Bella**（动作出口：冲向她住处/侧殿）。遗物哭丧**不做**，留给 34–35。

**第三幕·钩子**  
人在抓捕路上/砸开 Bella 房门前一秒。  
**反击拍**：本集 Ava 昏迷，反击延后；城堡温柔 vs 夜嚎仇杀对照。  
**主视觉**：床前恨眼 / 三子持「凶手是 Bella」冲出。  
**出口→33**：抓捕场开打——门后应是空的。  
**信息差**：观众知 Ava 活且将醒；三子认死+归罪 Bella。

### 第33集｜抓 Bella 扑空 → 有限醒悟「被骗」

**入口**：紧接 32——砸开/闯入 Bella 常驻处。  
**本集功能**：抓 Bella→跑了；有限醒悟「被 Bella 骗了」。**仍不进入大段哭丧**。  
**主场**：日外/内·Bella 住处或侧殿闺房；林缘逃痕。  
**人物**：Lucas、Ryan、Jason；（Bella 缺席）；可有侍从报「人早走了」

**第一幕·建立**  
门开——空的。仇无处撒。

**第二幕·升级**  
1. 翻箱：逃乱衣物、后门泥靴印、心形项链相关痕迹/空瓶位。  
2. 银屑药/「巫师开的药」对上空位——Lucas 30 见银屑在此坐实「她跑了=心虚=害死 Ava」。  
3. 三人从「Bella 不会害我们」裂到「她骗了我们」「她杀了 Ava」。  
4. **醒悟停在 Bella**：不上升到「我们才是主凶」。怒火见顶后开始发空——为 34 怒转悲铺垫，但本集高潮是抓空与被骗，不是跪哭遗物。

**第三幕·钩子**  
空巢+骗局裂口；怒意开始塌成空茫。  
**主视觉**：空房翻箱 / 逃痕。  
**出口→34**：这才转去 Ava 旧痕迹，开哭丧怀念。  
**亮点**：抓空比抓到更火；反转：救命美人变逃凶。

### 第34集｜抓空之后 → 哭丧怀念（痕迹 / 回忆 / 物件）

**入口**：承接 33——抓空怒意塌下；有人先哑火，有人砸墙后蹲下；「她真的死了」。  
**本集功能**：**审核锁定的哭丧段**——火葬场预热；悔与自怜并行；仍认她死。  
**主场**：日内·Ava 旧卧 / 仓库 / 林缘旧地（可选 1–2 场）。  
**人物**：Lucas、Ryan、Jason；闪回可短切（勿冗）

**第一幕·建立**  
回到 Ava 旧卧：灰尘、空床、未收小物——这才抱遗物。

**第二幕·升级**  
1. **物件拍**：狼牙项链记忆、焦黑月丝、割徽伤口记忆、碎戒、烧衣灰——每件触发一句「我们曾……」。  
2. **短闪回**（用已出场场号）：6-2 救命承诺 / 7 烧袍 / 19 割徽 / 27 毁戒——点到为止。  
3. Lucas 悔最沉；Ryan 怒哭砸物；Jason 哭软。  
4. 自怜句必须露头：「都是 Bella……」「若不是她骗我们……」「我们本来是爱她的」——罪仍外置，为 39 Ava 讽刺埋伏。

**第三幕·钩子**  
哭丧未完，情绪更重。  
**主视觉**：手握焦布/空床泪。  
**出口→35**：怀念推顶 → Silas 找来。  
**亮点**：先仇后哭，情绪更真；反转：越怀念越像给自己开脱。

### 第35集｜哭丧至顶 → Silas：她没死

**入口**：怀旧哭丧场未散；三子仍以丧礼语气说话。  
**本集功能**：把「死了」推到最满，再一句话掀桌——还活着。  
**主场**：日内·旧卧或议事厅。  
**人物**：Lucas、Ryan、Jason、Silas（后半）

**第一幕·建立**  
再一件遗物/再一句「来不及了」；可提「Bella 跑了，连仇都报不成」。

**第二幕·升级**  
1. 三人立誓：日后抓到 Bella 祭她、守夜嚎、如何「配得上死去的 Ava」——虚假庄重（抓捕已失败，誓言落在「日后」）。  
2. **Silas 入场**（伤愈或扶墙而来）：打断——Ava **没有死**。  
3. 三子震惊、不敢信、追问。本集可先停在「没死」巨钩，细节留给 36；或 Silas 只说一句实证引子（探子/城堡线）吊住。

**第三幕·钩子**  
「她没死」落地；世界从丧礼切回争夺。  
**主视觉**：丧礼表情碎裂。  
**出口→36**：Silas 展开解释。  
**亮点**：假丧礼被一句活讯砸穿。

### 第36集｜没死才族安 → 真狼王 → 自信上门抢人

**入口**：紧接 35——三子追问「什么叫没死」。  
**本集功能**：Silas 给存活逻辑+情报；三子自恋发动机重启；上路。  
**主场**：日内·议事厅/Silas 书房。  
**人物**：Silas、Lucas、Ryan、Jason

**第一幕·建立**  
Silas：正因为她没死，夜嚎现在才能好好的（呼应不能杀/咒；圣石碎是预兆加压，族未灭因人还在）。

**第二幕·升级**  
1. 打听结果：她在 Roman 的城堡，活得好好的。  
2. 结论：Roman **真的是狼王**——打脸「骗子」口径。  
3. 三子短暂懵→立刻改口术：那更要去接回来；狼王配不上十年感情；我们道歉她就会回来。  
4. **自信满档**：只要反省的样子做到位+把 Bella 的锅认清，Ava 必弃 Roman、回夜嚎。  
5. 整装上路（或宣示明日即至）——出口动作明确。

**第三幕·钩子**  
三子自信剪影上路/出城。  
**反击拍**：观众已知 Ava 心死——自信即笑柄。  
**主视觉**：出城背影 / Silas 预言焦虑眼神。  
**出口→37**：人将至城堡；镜头切城堡内 Mira 线。  
**亮点**：真狼王情报不带来臣服，只带来抢人自信。

### 第37集｜Mira 害 Ava（嫉妒拉扯）

**入口**：狼王城堡——Ava **已醒**（或本集开头醒来）；身体仍虚；Theo 可送水后离开；三子未入画或城外将至。  
**本集功能**：Mira 因妒+爱慕动手；与 Ava 情绪/动作拉扯；害局悬着。  
**主场**：日内·卧房/回廊/露台（择一主战场）。  
**人物**：Ava、Mira；（Theo 可短暂）；Roman 可不在场（族务/书房），避免秒解

**第一幕·建立**  
Mira「照料」过度；话里带刺；Ava 冷、短、不吃这套。

**第二幕·升级**  
1. Mira 摊牌式嫉妒：同是 OMEGA，凭什么。  
2. **害人手段（择一主做，理由满）**：药茶（非银/或误加刺激物）、推下阶、持银饰刺（银=伤，非净）、捂鼻——须见动作层次与被拆穿风险。  
3. **Ava 反击拍**：极寒一点/狼力一震/掀桌/反制手腕——虚仍打得动。  
4. 拉扯拉满：骂、抢、摔，未分胜负或 Mira 暂居上风——为 38 闯入留缝。

**第三幕·钩子**  
害局进行中：手中凶器/药杯将倾/人将推下——**未完**。  
**主视觉**：OMEGA 对 OMEGA 的恨眼；杯中异常色。  
**出口→38**：同一冲突场，门破——三子赶到。  
**亮点**：新恶女小刀；反转：外患未平内妒起。

### 第38集｜三子撞见 → 讨好式教训 Mira → 甩锅 Bella

**本集功能**：撞见→教训女仆讨好；自承「很多是 Bella 干的」。  
**主场**：同 37 冲突场。  
**人物**：Ava、Mira、Lucas、Ryan、Jason

**第一幕·建立**  
三子一眼看见：女仆对 Ava 动手。Ryan 最先暴起。

**第二幕·升级**  
1. **教训 Mira**：摔、斥、禁足式殴打（不写死）；对 Ava 献宝式「我们保护你」。  
2. Mira 哭喊求饶/骂 Ava 狐狸精——被压下。  
3. 三子转向 Ava：热脸——我们来接你回家；很多事是 Bella 骗我们干的，我们已经知道了。  
4. Ava 眼神冷，尚未大段讽刺（留给 39）——本集可先回一句刺，或沉默让他们表演。

**第三幕·钩子**  
讨好式英雄演完；空气僵。  
**反击拍**：Ava 不接梗、不谢。  
**主视觉**：三子按着 Mira 像献俘。  
**出口→39**：同一客厅/同一僵局，Ava 开口钉死。  
**亮点**：护驾动机不纯一目了然。

### 第39集｜Ava 讽刺：凡事推别人

**入口**：紧接 38——Mira 已倒/被拖走；三子还在等一句「谢谢/原谅」。  
**本集功能**：Ava 讽刺升级：什么都推到别人身上，看不到自己的问题。  
**主场**：同场或侧厅。  
**人物**：Ava、Lucas、Ryan、Jason；（Roman 可远处未入）

**第一幕·建立**  
Lucas 试探：我们是真心反省。  
Ryan：Bella 跑了，都是她。  
Jason：求你回家。

**第二幕·升级**  
1. Ava 逐条拆：药是谁灌的、戒是谁踩的、衣是谁烧的、拳是谁打的——**名字是你们**。  
2. 核心句功能：你们总把事情推到别人身上，从来不看自己。  
3. 三子脸变——但尚未崩溃成真醒；开始「错听」准备（留给 40）。  
4. Ava：我不想看见你们。

**第三幕·钩子**  
讽刺钉死；三子眼神却出现「她在给台阶」的歪解前兆。  
**反击拍**：本集主反击=语言处决。  
**主视觉**：Ava 站着，三子矮一截。  
**出口→40**：歪解发酵。  
**亮点**：悔过表演被当场撕皮。
