### 第31集｜破牢救美 → 代罚 → 抱走 → 圣石前昏厥

**入口（30→31）**：古老地下囚牢——地动未停；Ava 闭眼垂手；Lucas 手中/眼前银屑药；「不准死」余音未落。

**主场**：日内·古老地下囚牢 → 日外·祭祀广场（碎石）。  
**人物**：Roman、Ava、Lucas、Ryan、Jason、Bella（逃影/空镜）、Silas；可有侍从惊呼

**第一幕·建立**  
地动中牢门/石壁崩裂感；三子围假死身；Lucas 仍盯银屑。威压先至——**Roman 破入**（紫金狼威/人形亦可）。

**第二幕·升级**  
1. Roman 一眼看穿银伤、假死、囚牢——当场罪证满档。  
2. **代罚**：不杀；可摔砸、跪压、狼威镇压、当众断其嚣张（Ryan 最先扑最先挨）。对白少而狠：伤我的 Mate，罚你们。  
3. Lucas 或喊「药有银/Bella——」——乱局未审完；药瓶可被碰落/Roman 收走一拍（为33醒悟留物证链，勿在本集审完禁药）。  
4. Roman 抱起 Ava（动作轻、眼神冷对三子）。  
5. **侧写 Bella 逃**：乱中心形项链影/侧廊人影窜出/后门开合——观众知她跑，三子本集可未追。  
6. 转场：Silas 冲到祭祀广场，看见圣石**全碎**一地，急得发抖：人明明关牢里，为何还碎？想不通。  
7. 三子带伤跑来报：Ava 被那个骗子 Roman 带走了！  
8. Silas 震惊、不敢置信，嚷「夜嚎狼群要完了」——**晕厥**。

**第三幕·钩子**  
Silas 倒在碎石前；人已被抱走的事实钉死。  
**反击拍**：Roman 代罚=女主欠债由 Mate 当面讨。  
**主视觉**：破牢狼威 / 抱走剪影 / 碎石堆前昏厥。  
**出口→32**：

- B：Silas **仍倒在碎石上**；三子带伤围着（交给32同广场惊魂→定性 Bella）。  
**亮点**：救美+代罚+碎石恐慌三线同集；反转：关牢「万无一失」仍碎→人还被狼王拿走。

2. 台词锁定：你平平无奇，跟我一样也是 OMEGA，凭什么你就能嫁给 Roman。

4. **转场句**：与此同时 / 另一边——**碎石广场**。三子看着昏厥的 Silas，惊魂复盘：人「死了」、药有银屑、药是 Bella 的。  
5. **定性**：Bella 害死了 Ava。怒大于悲。  
6. **出门抓 Bella**：从广场冲向她住处；手触门/门将破——**定格**。哭丧不做。

**第三幕·钩子**  
门将破。  
**出口→33**：同一扇门破开=空房。  
**信息差**：观众知 Ava 活；三子认死+归罪 Bella。

### 第33集｜抓 Bella 扑空 → 有限醒悟「被骗」

**入口（32→33）**：32 末「门将破」的下一帧——门板迸开/闯入，空房扑面。  
**本集功能**：抓 Bella→跑了；有限醒悟「被骗」。**仍不进入大段哭丧**。  
**主场**：日内·Bella 住处；可跟一步后门逃痕。  
**人物**：Lucas、Ryan、Jason；（Bella 缺席）

**第一幕·建立**  
空的。吼声砸进空墙。

**第二幕·升级**  
1. 翻箱：逃乱衣、泥靴印、空瓶位。  
2. 对上银屑药——坐实心虚=害死 Ava。  
3. 「她骗了我们」有限醒；罪仍外置 Bella。  
4. 怒顶后塌成空茫；有人握紧空瓶；有人喃「她真的死了」。

**第三幕·钩子**  
空房里站不住——往外走的脚步起。  
**出口→34**：离开空房→走向 Ava 旧卧（可见脚步/走廊），怒转悲，**到了旧卧才哭**。  
**亮点**：抓空比抓到更火。

### 第34集｜抓空之后 → 哭丧怀念（痕迹 / 回忆 / 物件）｜**本批台词最厚场之一**

**入口（33→34）**：自 Bella 空房走出的走廊/院落→推开 Ava 旧卧门；手中可仍握空瓶。怒已塌，悲才起。  
**本集功能**：**哭丧段**——火葬场预热；悔与自怜；仍认她死。  
**主场**：日内·Ava 旧卧（主场钉死，勿无故跳林缘开场）。  
**人物**：Lucas、Ryan、Jason

**第一幕·建立**  
空床、灰尘、未收小物——抱起遗物，哭出声。

**第二幕·升级（台词加厚）**  
1. 物件拍：狼牙记忆、焦月丝、割徽疤、碎戒、烧衣灰——**每件至少 2–3 轮**三人对谈，勿一件一句。  
2. 短闪回点到为止（6-2 / 7 / 19 / 27），闪回后必须接「现在时」怀念对白。  
3. Lucas 沉悔领唱；Ryan 怒哭砸物；Jason 软哭捡话——三人声线分开。  
4. 自怜+甩锅交织：「都是 Bella 害我们」「我们本来爱她」「若不是她挑拨」——为 39 讽刺埋伏。  
5. 细腻：半句哽住、叫小名/旧称呼、说「她以前……」说不完；禁口号式后悔。

**第三幕·钩子**  
哭到喘不过气；手中焦布不放。  
**出口→35**：**人不离旧卧**；焦布还在手里；门将响（Silas 将入）。  
**亮点**：先仇后哭。

### 第35集｜哭丧至顶 → Silas：她没死

**入口（34→35）**：同一旧卧；焦布/遗物仍在手；哭声未断。门被推开。  
**本集功能**：哭丧推顶→「没死」掀桌。  
**主场**：日内·Ava 旧卧（与34同场）。  
**人物**：Lucas、Ryan、Jason、Silas

**第一幕·建立**  
再一句「来不及了 / Bella 跑了连仇都报不成」。

**第二幕·升级**  
1. 立假誓：日后抓 Bella 祭她。  
2. **Silas 推门入**（可带伤）：Ava **没有死**。  
3. 三子震惊追问「什么叫没死？她在哪？」——问句悬空，解释留给36。

**第三幕·钩子**  
「没死」二字砸碎丧礼。  
**出口→36**：同一追问未完，Silas 开口解释的下一句。  
**亮点**：假丧礼被活讯砸穿。

### 第36集｜没死才族安 → 真狼王 → 自信上门抢人

**入口（35→36）**：旧卧内，追问「没死？在哪？」的下一句——Silas 回答。  
**本集功能**：存活逻辑+情报；自恋重启；上路。  
**主场**：可仍在旧卧说完再移步院落整装；勿无对白瞬移出城。  
**人物**：Silas、Lucas、Ryan、Jason

**第一幕·建立**  
Silas：正因为她没死，夜嚎现在才能好好的。

**第二幕·升级**  
1. 她在 Roman 城堡，活得好好的。  
2. Roman **真是狼王**。  
3. 三子改口：去接回来；道歉她就会弃 Roman。  
4. 自信满档→整装→**出城上路**（脚步/城门必须看见）。

**第三幕·钩子**  
出城背影。  
**出口→37**：  
- 夜嚎线：人在路上（可在37用一句马蹄/城影接住）；  
- 城堡线：时间已过数时辰，Ava 该醒——37 开场接苏醒/已醒。  
**亮点**：真狼王情报只换来抢人自信。

### 第37集｜Mira 害 Ava（嫉妒拉扯）

**入口（36→37）**：  
- 城堡：Ava **醒来**（眼睫动/坐起），伤仍在；呼应32「几个时辰」。Mira 以照料为名靠近（恨种自32）。  
- 可短切一句：三子马队将近狼王城堡（接36出城）。  
**本集功能**：Mira 动手害 Ava；拉扯；害局悬着给38撞见。  
**主场**：日内·卧房（建议钉死同房，便于38同场闯入）。  
**人物**：Ava、Mira；（Theo 可送水后离开）；Roman 不在场

**第一幕·建立**  
醒来→Mira 过度照料→话里带刺；Ava 冷回。

**第二幕·升级**  
1. Mira 摊牌：同是 OMEGA，凭什么。  
2. 害人（药茶/推搡/银饰刺等，银=伤非净）。  
3. Ava 反击（极寒/掀桌/反制）。  
4. 拉扯未完——杯将灌/人将推。

**第三幕·钩子**  
动作冻结在将成未成。  
**出口→38**：同一姿势，门破，三子闯入（路上线合并到场）。  
**亮点**：内妒起刀。

### 第38集｜三子撞见 → 讨好式教训 Mira → 甩锅 Bella

**入口（37→38）**：37 末将灌/将推的同一帧——门破，三子闯入，亲眼看见。  
**本集功能**：教训 Mira 讨好；甩锅 Bella。  
**主场**：**与37同一房间**。  
**人物**：Ava、Mira、Lucas、Ryan、Jason

**第一幕·建立**  
Ryan 最先把 Mira 从 Ava 身上拽开。

**第二幕·升级（台词加厚）**  
1. 教训 Mira（不写死）同时对 Ava 献宝「我们保护你」——讨好要肉麻、要自以为是。  
2. Mira 被制住；三子热脸不退。  
3. **甩锅专场**：Lucas/Ryan/Jason 轮流说「很多事是 Bella 干的」「她害我们失去理智」「我们不是那样的人」——变体多轮，勿一句带过。  
4. Ava 冷眼短刺或不谢——大段处决留39，但本集已让观众听腻他们的甩锅。

**第三幕·钩子**  
空气僵；三子还在等原谅。  
**出口→39**：人不散场，下一秒 Ava 开口。  
**亮点**：讨好式护驾。

### 第39集｜Ava 讽刺：凡事推别人｜**本批台词最厚场之一**

**入口（38→39）**：同一房间僵局；Mira 已倒/被拖走；三子热脸未退。  
**本集功能**：Ava 讽刺——推别人、看不见自己。  
**主场**：与38同场。  
**人物**：Ava、Lucas、Ryan、Jason

**第一幕·建立**  
Lucas：真心反省。Ryan：都是 Bella。Jason：求你回家。

**第二幕·升级（台词加厚）**  
1. 三子先表演「反省」：轮流甩锅 Bella（害我们、骗我们、我们才伤她）——每人至少一轮。  
2. Ava 逐条拆：灌药/毁戒/烧衣/出拳——名字是你们；每拆一条，允许他们辩一句再拆穿。  
3. 核心钉死：总推别人，不看自己。  
4. Ava：不想看见你们。  
5. 三子脸变，却已在眼中酝酿歪解（「她在指路」）——情感是羞恼+不甘+仍自恋，不是真醒。

**第三幕·钩子**  
讽刺钉死；歪解眼神留下。  
**出口→40**：同厅，下一秒三子开始复盘歪解。  
**亮点**：悔过表演撕皮。

证词特写定格。
