# 剧本项目

每部剧一个独立文件夹,互不干扰。对 Agent 说 `新建项目:剧名` 即可从 `短剧续写工作流/项目模板/` 自动创建。

每个项目文件夹的结构:

```text
剧本项目/<剧名>/
├── 01_资料库/        ← 这部剧的一卡剧本、人物圣经、世界观、伏笔清单、项目定位、对标剧原文
├── 04_产出/          ← 这部剧的结构卡、总纲、集纲、正文、自检报告(带版本号)
└── 状态看板.md       ← 这部剧写到哪一步了
```

规则:

- 工作流阶段(S0–S5)、返修机制对所有项目通用,定义在 `短剧续写工作流/`。
- 每部剧只以**自己的一卡剧本**为正文源头,Agent 严禁把 A 剧的人物、设定、桥段带进 B 剧。
- 多个项目并行时,给 Agent 的指令带上 `项目:剧名`。
