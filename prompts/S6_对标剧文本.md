# S6 · 对标剧文本（循环批次起点）

> 阶段目标：向 AI 提供本批次要参考的对标剧文本（**可以有多个，也可能完全没有**），并强制 AI 先把对标降维成"抽象结构"，隔离具体情节。
> **如果本批次完全没有对标文本：跳过本阶段，直接进入 S7**（S7 模板对无对标情况有专门写法）。
> 产出归档：`projects/<剧名>/批次XX_第XXX-XXX集/S6_对标抽象结构.md`

## 提示词模板

```text
【S6 对标剧文本 —— 第 {{XX}}–{{XX}} 集批次】

以下是本批次的对标剧文本，共 {{N}} 部。

再次强调硬性规则：
- 你只能从中提取抽象层：冲突类型、单集钩子类型、信息释放节奏、情绪曲线。
- 禁止使用其中任何具体对白、人物设定、标志性场面。
- 若内容太具体、无法安全借鉴，你必须拒绝照搬，只提取抽象结构。

=== 对标 1《{{对标剧名}}》第 {{XX}}–{{XX}} 集 ===
{{粘贴对标剧文本}}
=== 对标 1 结束 ===

{{如有多个对标，依次粘贴 对标2、对标3……}}

请对每部对标输出一份【抽象结构报告】，只允许包含以下内容：

1. 冲突类型序列：每集的冲突归为哪一类（用类型词，禁止复述情节细节。
   类型词示例：身份暴露危机 / 第三方介入 / 利益胁迫 / 误会升级 / 公开羞辱与反击）
2. 钩子类型序列：每集结尾钩子归为哪一类（悬念钩 / 反转钩 / 危机钩 / 情感钩 / 身份钩）
3. 信息释放节奏：这段剧里，观众与各方角色的信息差如何布置、何时拉平
4. 情绪曲线：这段剧的情绪起伏形态（用"压抑→爆发→反噬→翻盘"这类抽象描述）
5. 危险清单：这部对标中辨识度过高、绝对不能出现任何变体的
   "独特梗 / 标志性场面"，逐条列出（此清单将交给 S10 做防侵权检验）

不要输出任何对标剧的对白引用或具体情节复述。

【等待指令】
```

## 备注

- 【危险清单】是 S10 防侵权检验的输入，必须妥善归档。
- 多部对标时，可在报告末尾让 AI 补一段"多对标交叉参考建议"：不同对标各取哪个维度。
