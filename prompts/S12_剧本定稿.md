# S12 · 剧本定稿（批次收尾）

> 阶段目标：本批次（第 XX–XX 集）剧本正式定稿归档，更新全剧状态，为下一批次循环做准备。
> 产出归档：`projects/<剧名>/批次XX_第XXX-XXX集/S12_剧本_定稿.md`

## 定稿前最终检查清单

- [ ] S8 定稿集纲的每一项设计（冲突/信息差/钩子）都在正文中落实
- [ ] S10 检验报告全部场面判定"安全"
- [ ] S11 润色完成且未改动剧情结构
- [ ] 格式与一卡剧本一致（可直接进入拍摄/翻译流程的程度）
- [ ] 批次结尾状态明确（为下一批次 S7 的"衔接"提供锚点）

## 提示词模板（定稿归档 + 状态快照）

```text
【S12 剧本定稿 —— 第 {{XX}}–{{XX}} 集】

本批次剧本正式定稿。请输出【批次收尾包】，供下一批次使用：

1.【定稿正文】第 {{XX}}–{{XX}} 集最终版全文（S11 润色版，不再改动）

2.【剧情状态快照】（下一批次 S7 的衔接依据）
   - 定稿结尾时刻：各主要角色的处境、彼此的信息差状态
   - 本批次推进后，主线走到了哪一步
   - 结尾钩子留下的"待解问题"清单

3.【伏笔变动记录】（用于回填 S4 台账）
   - 本批次回收的旧伏笔（编号 + 回收集数）
   - 本批次新埋的伏笔（内容 + 埋设集数 + 建议回收范围）

4.【下一批次建议】
   - 建议的下一批集数范围与阶段主题
   - 按 S3 排期表，下一批次是否含付费卡点/大结局

【等待指令】
```

## 批次循环

定稿后回到 `S4`（用"批次更新"模板回填伏笔台账），然后开启下一批次：

```
重复 S6 →（提供下一批对标文本，或无对标直接跳过）
重复 S7 →（生成下一批集纲）
重复 S8 →（审核）
重复 S9 →（续写）
重复 S10 →（防侵权检验）
重复 S11 →（去AI味）
重复 S12 →（定稿）
……直至写满目标集数（默认 55 集），大结局批次在 S7 控制参数中标注
"本阶段结尾是否大结局：是"。
```
