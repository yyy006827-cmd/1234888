# S0-0 · 新建剧名

> 阶段目标：确定这部剧的正式剧名（中文工作名 + 英文上线名），并建档。
> 产出归档：`projects/<剧名>/00_剧目档案/S0-0_剧名.md`

## 提示词模板

```text
【S0-0 新建剧名】

我要新建一部海外短剧项目。以下是这部剧的基本方向：

- 题材方向：{{例：狼人Alpha / 亿万富翁替嫁 / 复仇甜宠 / 隐藏身份}}
- 核心卖点一句话：{{例：被弃的Omega其实是失踪的月神继承人}}
- 目标受众：{{默认：北美女性}}

请你：
1. 给出 10 个英文剧名候选（符合北美短剧平台命名习惯：直给、带身份钩子、
   常用 Alpha/Billionaire/Divorce/Secret/Baby 等高点击词，但避免与已上线爆款完全撞名）。
2. 每个候选附一句"为什么能提升点击率"的理由。
3. 给出对应的中文工作名。
4. 推荐你认为最强的 1 个，并说明理由。

【等待指令】后，我会选定剧名并确认建档。
```
