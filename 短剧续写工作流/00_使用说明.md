# 短剧续写工作流 · 使用说明

## 一句话怎么用

你把资料放进 `01_资料库/`,然后每次只需要对 Agent 说一句话,例如:

```text
执行 S3,范围:二卡第13–16集
```

Agent 会自动读取 `02_阶段提示词/` 里对应阶段的提示词和 `01_资料库/` 里的资料,产出结果放进 `04_产出/`。
你审完后,要么说"通过,进入下一阶段",要么填一张返修单丢回来,Agent 重写。

**你永远不需要再手打长提示词。**

---

## 术语约定

| 术语 | 含义 |
|------|------|
| 一卡剧本 | 你已完成的付费卡点前剧本(即已有的前12集),是全剧唯一正文源头 |
| 二卡及后续 | 从第13集起需要续写的部分 |
| 对标剧 | 参考剧,只允许抽象层借鉴,禁止任何具体表达的改写 |
| 结构卡 | 从对标剧提炼出的抽象结构(冲突类型/钩子类型/节奏),不含原文 |
| 圣经 | 人物小传 + 世界观 + 伏笔表的合称,人设与设定的最高裁决依据 |

---

## 流水线总览(每一步都有审核关卡)

```text
S0 资料入库检查 ──审核──▶ S1 对标结构卡提炼 ──审核──▶ S2 二卡总纲规划
                                                        │审核
                                                        ▼
        S5 原创性自检 ◀──审核── S4 正文剧本(每批2–4集) ◀──审核── S3 分批集纲
             │审核
             ▼
       通过 → 归档,进入下一批(回到S3)
```

| 阶段 | 做什么 | 产出位置 | 审核点 |
|------|--------|----------|--------|
| S0 | 检查资料是否齐全、有没有矛盾 | 对话中直接汇报 | 你确认资料无误 |
| S1 | 把对标剧提炼成抽象结构卡(只做一次) | `04_产出/S1_对标结构卡/` | 结构卡里不得残留原文表达 |
| S2 | 规划二卡到大结局的总纲(arc 级) | `04_产出/S2_总纲/` | 主线走向、卡点设计你满意 |
| S3 | 按批次写集纲(只写冲突/钩子/新颖点,不写对白) | `04_产出/S3_集纲/` | 逐集确认,不像对标翻版 |
| S4 | 按已通过的集纲写正文剧本 | `04_产出/S4_正文/` | 人设不崩、钩子够强 |
| S5 | 原创性与侵权风险自检报告 | `04_产出/S5_自检报告/` | 三问检验全部通过 |

**铁律:上一阶段没通过审核,不进入下一阶段。S3→S4→S5 按批次循环,每批 2–4 集。**

---

## 你要说的话(全部指令一览)

| 你说 | Agent 做 |
|------|----------|
| `执行 S0` | 检查资料库,列出缺什么 |
| `执行 S1` | 生成对标结构卡 |
| `执行 S2` | 生成二卡及后续总纲 |
| `执行 S3,范围:第X–Y集` | 生成该批集纲 |
| `执行 S4,范围:第X–Y集` | 按已通过集纲写正文 |
| `执行 S5,范围:第X–Y集` | 出自检报告 |
| `通过` | 归档当前产出,提示下一步 |
| `返修` + 返修单(或直接口头意见) | 按意见重写,版本号+1 |
| `当前进度` | 读状态看板,汇报到哪一步了 |

返修单模板在 `03_审核与返修/返修单模板.md`,但**口头一句话意见也可以**,例如:
"返修,第14集反转太靠巧合,改成女主主动设局"。

---

## 开工前准备(最小可行包)

把以下文件放进 `01_资料库/`(每个都有模板,照着填):

1. `一卡剧本.md` —— 你已有的前12集完整剧本(必给)
2. `人物圣经.md` —— 核心人物小传,含说话方式(必给)
3. `世界观圣经.md` —— 规则、阶层、禁忌(必给)
4. `伏笔清单.md` —— 已埋的线,哪些必须回收(必给)
5. `项目定位.md` —— 受众/平台/单集时长/目标集数/写作禁区(必给)
6. `对标剧原文/` —— 对标剧剧本,仅供 S1 提炼用,S2 之后不再读取(可选,也可以你自己填结构卡)

资料齐了就说:`执行 S0`。
