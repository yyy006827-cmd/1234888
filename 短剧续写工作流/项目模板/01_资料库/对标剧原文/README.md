# 对标剧原文(仅限 S1 阶段读取)

把对标剧剧本按集放在本目录(命名如 `对标_第01集.md`)。

## 使用限制(Agent 必须遵守)

1. 本目录内容**只在 S1 阶段读取一次**,用于提炼抽象结构卡。
2. S2 及之后的任何阶段,**禁止再读取本目录**,只允许使用 `04_产出/S1_对标结构卡/` 里已通过审核的结构卡。
3. 提炼时禁止摘录原文对白、场景描写、独特设定名称;只输出类型级描述。

> 如果你不想上传对标剧原文,也可以跳过 S1,自己照着 `02_阶段提示词/S1_对标结构卡提炼.md` 末尾的结构卡模板手工填写,放进 `04_产出/S1_对标结构卡/`。
