# S0 · 资料入库检查

> 触发指令:`执行 S0`

## 任务

通读 `01_资料库/` 全部文件,输出一份资料体检报告,不做任何创作。

## 检查项

1. **齐全性**:一卡剧本 / 人物圣经 / 世界观圣经 / 伏笔清单 / 项目定位,是否都已填写?列出缺失或仍是模板占位的文件。
2. **一致性**:一卡剧本与人物圣经/世界观是否有矛盾(人名、称谓、规则、时间线)?逐条列出。
3. **伏笔核对**:通读一卡,找出剧本里实际埋了、但《伏笔清单》漏记的线,建议补录。
4. **人物卡完整度**:哪些出场人物没有人物卡?哪些人物卡缺"说话方式"?
5. **续写起点快照**:用一页纸总结第12集结束时——每个核心人物的位置、掌握的信息、情感进度、悬而未决的冲突。

## 产出

在对话中直接输出报告,末尾给结论:
- `可以开工` → 提示用户下一步执行 S1(或已有结构卡则 S2)
- `需补资料` → 列出待办清单

## 审核关卡

用户确认资料无误或补齐后,才进入 S1。
