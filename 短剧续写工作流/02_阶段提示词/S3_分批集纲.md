# S3 · 分批集纲(不写对白)

> 触发指令:`执行 S3,范围:第X–Y集`(每批2–4集)
> 前置条件:S2 总纲已通过;若本批不是第一批,上一批 S5 已通过

## 任务

按已通过的总纲,写本批每一集的集纲,写入 `04_产出/S3_集纲/第X-Y集集纲_v1.md`。

**只写结构,不写对白,不写场景描写。禁止读取对标剧原文。**

## 每集集纲格式

```markdown
## 第N集

- **核心冲突**(一句话,抽象):
- **主动方 / 被动方**:
- **信息差**(谁知道什么、观众知道什么):
- **场景**(必须来自《世界观圣经》的标志性场景清单,或从本剧世界观自然长出):
- **推进的主线 / 触碰的伏笔**(引用编号):
- **结尾钩子**(类型 + 一句话):
- **新颖点**(为什么这不是对标翻版;对应新颖性三原则的哪一条):
- **人设咬合**(本集关键行为如何符合相关人物卡的目标/底线/说话方式):
```

## 批次末尾附

1. **本批与总纲的对照**:是否偏离,偏离处说明理由
2. **原创性三问自答**(逐集)
3. **下一批预告**(一句话,方便用户提前把关方向)

## 审核关卡

用户逐集确认。常见返修理由:像对标某集 / 反转靠巧合 / 人物OOC / 钩子弱。
返修输出 `第X-Y集集纲_v2.md`。**集纲未通过,严禁开写正文。**
