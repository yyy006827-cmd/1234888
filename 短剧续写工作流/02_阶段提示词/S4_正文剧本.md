# S4 · 正文剧本

> 触发指令:`执行 S4,范围:第X–Y集`
> 前置条件:该范围的 S3 集纲已通过审核

## 任务

严格按已通过的集纲写完整剧本,写入 `04_产出/S4_正文/第X-Y集剧本_v1.md`。

**禁止读取对标剧原文。禁止偏离已通过的集纲;若写作中发现集纲有问题,停下来向用户申请修订。**

## 写作要求

1. **格式**:场景标题(内/外·地点·日/夜)+ 动作描写 + 对白,符合《项目定位》的单集时长与语言要求。
2. **对白**:每个人物的台词必须能通过"遮名测试"——遮住名字,凭说话方式能认出是谁(依据《人物圣经》)。
3. **场景**:只用本剧世界观里的场景,不移植对标场景壳。
4. **钩子**:每集最后一个画面/一句台词必须落在集纲规定的钩子上,卡点集加强。
5. **爽感节奏**:按《项目定位》的调性执行;冲突当集有小兑现,大兑现按总纲位置留。

## 每集末尾附「原创性自检」

- 本集若删除对标参考,是否仍从一卡与总纲自然成立?
- 是否存在可识别的标志性桥段对应?
- 是否存在对白近义改写?
- 是否仅移植了场景壳?
- 任何一项有风险 → 直接重写该段后再交付,不辩解。

## 审核关卡

用户按集审:人设、钩子、爽感、台词质感。
返修输出 `第X-Y集剧本_v2.md`,只改被指出的问题及连带影响。通过后进入 S5。
