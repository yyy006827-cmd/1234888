# 返修单模板

> 复制下面的表填好发给 Agent 即可。**懒得填表也行**,直接一句话说清"哪一集/哪一段 + 什么问题 + 想要的方向",效果一样。

```markdown
## 返修单

- **针对产出**:(如:S3 第13–16集集纲 v1)
- **总体结论**:返修

### 意见清单
| # | 位置 | 问题类型 | 具体意见 | 期望方向 |
|---|------|----------|----------|----------|
| 1 | 第14集反转 | 太像对标 / 靠巧合 / OOC / 钩子弱 / 节奏拖 / 其他 | (说清哪里不对) | (想改成什么样,可留空让Agent提方案) |
| 2 | | | | |

### 保留项(明确不许动的部分)
- (如:第13集全部保留;第15集结尾钩子保留)
```

## 问题类型速查

| 类型 | 含义 |
|------|------|
| 太像对标 | 能被指认对应对标某桥段,必须换引擎重造 |
| 靠巧合 | 推进靠偶遇/听墙角/掉东西,改为人物主动行为 |
| OOC | 台词或行为不符合人物卡 |
| 钩子弱 | 结尾停不住手指,需加强 |
| 节奏拖 | 冲突兑现太慢,压缩或前移 |
| 逻辑洞 | 信息差/时间线对不上 |
| 越纲 | 偏离已通过的总纲/集纲 |

## Agent 处理返修的规则

1. 先复述对每条意见的理解,有歧义先确认。
2. 只改意见涉及的部分及其连带影响,"保留项"一字不动。
3. 新版本号+1,旧版本保留;新版开头附《修改说明》:每条意见如何落实。
