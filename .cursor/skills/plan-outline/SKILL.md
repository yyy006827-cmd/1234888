# Plan Outline

## 步骤

1. 阅读 `manuscript/premise.md` 与 `novel.config.yaml`。
2. 补全或更新：`characters.md`、`world.md`、`style.md`。
3. 写 `outline.md`：每章包含标题、必须发生、情绪、章末钩子。
4. 初始化 `continuity.md` 伏笔账本。
5. 将 `STATUS.md` 阶段设为 `draft`，填好第 1 章信息。
6. 不要开始写正文，除非用户明确要求。
